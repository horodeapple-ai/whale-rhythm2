## 0. 一句话：这一版修的是**地基**

上一版（`新建文件夹\`）我判"节拍网格 128.35 够用、不需要换常量"——**这个结论是错的**。
这次我做了独立复核，决定性证据是「正拍 vs 反拍」的低频起音能量比（无噪声、不依赖相位恢复）：

| 段 | 恒定 128.35 网格 | 实测节拍表 |
|---|---|---|
| 全片 | 1.43× | **2.06×** |
| 前 50s | 2.05× | 2.31× |
| **70–100s（全片最响的 30 秒）** | **0.80×（<1：网格点上的鼓比反拍还少）** | **2.41×** |
| 110–140s | 1.10× | 1.34× |

用 12s 滑窗做梳状搜索独立恢复的局部速度也吻合这份表的说法：
主歌 126.7 → 副歌 128.3 → 中段爬到 131.0 → 桥段回落 128.5。
**恒速网格只在副歌 1（27–50s）对得上，越往后漂得越多**——所以上一版交付的"元素律动"在后半片是**踩在反拍上**的。
复现命令：`node tools/verify_beats.mjs`。

## 3.5 修掉的一个"播到某处卡死"（2026-10-07 晚）

**现象**：浏览器里播到 **14.25s** 画面停住（进度条不动，状态仍是"播放中"）。

**根因**：`src/opening-sample.mjs` 里 A-8「跨窗跑」那段用到了 `musicTime(...)`，但只 import 了
`playbackTime` —— `ReferenceError: musicTime is not defined`。它在 `renderFrame` 里抛出后，
`requestAnimationFrame` 的链就断了：**画面停在那帧、音频继续走**（所以看着像"卡死"，其实音频还在播）。

**为什么之前没查出来**：我的浏览器冒烟只抽了 5 个时间点（8 / 41.867 / 65.167 / 84.367 / 138.633），
**恰好都不落在 A-8（14.267–16.233）里**。

**修法与加固**：
1. 补上 import；
2. `tools/render_sweep.mjs`（新）：把**每一帧**都渲染一遍，任何一帧抛错立刻报出来 —— 全片 1401 帧（每 3 帧抽 1）**零异常**；
3. `tools/smoke_html.mjs` 改成**默认扫全片**（每 55 帧一个采样点，共 82 个时刻）—— 82/82 通过；
4. `tools/play_test.mjs`（新）：**真的点"播放"让音频走一段**，比较 `audio.currentTime` 与画面渲染时刻。
   已验：13.4→17.5s、25.5→29.5s、66.5→70.5s（跨最大 DROP）都是 **音画差 0.01s**；整片 0.4→139.6s 全程跑通。

**性能**（浏览器实测，非沙箱）：单帧平均 **2.5ms**，连续 120 帧里最慢 **7.3ms** —— 30fps 的预算是 33ms，余量充足。

### (2) 走路崩了（A-8 跨窗跑：腿被拉成一条直线）

**根因**：我把 A-8 的步频从恒定 BPM 换成实测节拍时，把步幅写死成 `step = v/2`，
而步数 `cycle` 是「Δ拍数 / 2」≈ `l × 1.075`。两者不同源 → `step × cycle` 只有 `v × l` 的 54%，
**脚相对身体一路往后漂**（最远 576 本地单位，而腿长只有 ~110）→ IK 够不到，腿被拉直。

**修法**：三个量用同一个 `walkRate` 推出来，守住恒等式 `step × cycle == v × l`：

```
walkRate = 1/(2 × 本拍时长)      每秒几步（1 步 = 2 个实测拍）
cycle    = Δ拍数 / 2             已走几步
step     = v / walkRate          每步位移
```

**全片核对**（新增 `tools/walk_check.mjs`：逐帧检查"脚是否被放到够不着的地方"，阈值 |foot| > 155）：

| 镜头 | 原始版 | 本版（修好后） |
|---|---|---|
| **A-8 跨窗跑** | 69 | **73**（修之前是 **576** ❌） |
| A-19 下一关来了 | 153 | 153 |
| A-5 / A-7 / A-11 | 61 / 52 / 55 | 61 / 52 / 55 |
| B-B03 / B-B07 / B-B10 / B-B12 | 58 / 50 / 52 / 52 | 58 / 50 / 52 / 52 |
| C-C04 | 44 | 44 |

→ **全片 4201 帧，没有任何一帧的脚超出可达范围；所有走路镜头的脚部位移与原始版逐镜头一致**
（只有 A-8 因改用实测步频 69→73，同一量级）。

**复现**：`node tools\walk_check.mjs`（本版）；`node tools\walk_check.mjs --srcroot=baseline`（原始版对照）。

### ⚠ 必须知道的踩坑：**目录名要用 ASCII**

`@napi-rs/canvas` 的原生绑定在**某些中文目录名下会直接段错误崩溃**（exit 0xC0000005，
`createCanvas()` 调用即崩，连 `try/catch` 都拦不住进程）。
实测：`Desktop\新建文件夹\` 能跑；`Desktop\大肥鱼-律动版2\` 必崩；`Desktop\_ascii_test\` 正常。
所以这一版的工程目录定名 `whale-rhythm-v2`。
**如果你要改名，请保持纯 ASCII**（里面的 HTML / mp4 文件名用中文没问题，崩的是模块所在的目录路径）。
